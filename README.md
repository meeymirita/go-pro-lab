# Go Pro — Go от среднего уровня до senior

**Часть 2 из 2.** Начало — [Go Start](https://github.com/meeymirita/go-start-lab) (с нуля до middle). Эта часть продолжает проект CoffeeGo оттуда; стартовый код выдаётся готовым, если первую часть не проходили.

13 сессий, 82 шага, около 72 часов. Сквозной проект **CoffeeGo Platform**: три сервиса (`orders`, `payments`, `notifications`), gRPC, очереди и Outbox, OpenTelemetry, Kubernetes. Темы: рантайм и GC, профилирование, паттерны конкурентности, архитектура и дизайн API, gRPC/OpenAPI, данные и очереди, наблюдаемость, надёжность, безопасность, продвинутые тесты, кодогенерация и свой анализатор кода, продакшн и CI/CD. Последняя сессия — самостоятельный проект без подсказок.
