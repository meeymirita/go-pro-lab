# Go Pro — Go от среднего уровня до senior

**Часть 2 из 2.** Начало — [Go Start](https://github.com/meeymirita/go-start-lab) (с нуля до middle). Эта часть продолжает проект CoffeeGo оттуда; стартовый код выдаётся готовым, если первую часть не проходили.

13 сессий, 82 шага, около 72 часов. Сквозной проект **CoffeeGo Platform**: три сервиса (`orders`, `payments`, `notifications`), gRPC, очереди и Outbox, OpenTelemetry, Kubernetes. Темы: рантайм и GC, профилирование, паттерны конкурентности, архитектура и дизайн API, gRPC/OpenAPI, данные и очереди, наблюдаемость, надёжность, безопасность, продвинутые тесты, кодогенерация и свой анализатор кода, продакшн и CI/CD. Последняя сессия — самостоятельный проект без подсказок.

**Статус: 🟡 методичка написана (13 сессий, 82 шага; пришла из другого чата 06.10.2026), НЕ вычитана и НЕ проверена запуском: ни один пример кода и ни одна команда не прогонялись. Вычитка (построчно, как у остальных лаб) и полный прогон кода запуском — впереди.**

## Порядок и что нужно до начала

Эта лаба идёт **строго после Go Start** (синтаксис, интерфейсы, ошибки, дженерики, горутины и `context`, `net/http`, `database/sql`, тесты, Docker). Сессии 7 и 13 опираются ещё на несколько лаб проекта, поэтому до Go Pro желательно пройти **Docker, PostgreSQL, Redis, RabbitMQ и Kubernetes** (Outbox и очереди, Compose-стенд, выкладка в кластер). Предварительные знания и версии (по описанию из чата, где писалась методичка; сверить при вычитке): Go (в тексте целевая 1.27), Docker с Compose v2, `kubectl` и `kind`, `k6`, `buf`, `graphviz`; PostgreSQL 18, Redis 8, RabbitMQ, Kubernetes 1.37 / kind v0.33.
